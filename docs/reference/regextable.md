# regextable: Tools for Regex Extraction and Cleaning

The regextable package provides functions for extracting patterns from
text using regex lookup tables and cleaning text data. It is
particularly useful for text analysis tasks where you need to match
multiple patterns.

## Main functions

- [`extract`](https://judgelord.github.io/regextable/reference/extract.md) -
  Extract pattern matches from text using regex lookup

- [`clean_text`](https://judgelord.github.io/regextable/reference/clean_text.md) -
  Clean and normalize text for consistent matching

## Datasets

- [`members`](https://judgelord.github.io/regextable/reference/members.md) -
  Lookup table of member names for regex matching

- [`cr2007_03_01`](https://judgelord.github.io/regextable/reference/cr2007_03_01.md) -
  Sample text data for demonstration
